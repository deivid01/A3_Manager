# A3 Manager

Aplicativo desktop offline para gestão de locações da A3 Locação de Equipamentos para Construção.

## Comandos principais

- `npm.cmd install`
- `npm.cmd run test`
- `npm.cmd run build`
- `npm.cmd run dist`
- `npm.cmd run validate:ui` (capturas responsivas do executável empacotado)
- `npm.cmd run measure:memory` (memória por processo após 10 segundos)

O banco SQLite local é criado no diretório de dados do usuário do Electron durante a execução instalada.
